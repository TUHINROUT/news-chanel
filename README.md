# Daily Express – Home Page (Next.js)

Only the home page, built with Next.js 14 (App Router).

## Run
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Structure
```
app/            layout.jsx, page.jsx, globals.css
components/     TopBar, Header, Navbar, BreakingNews, Hero, SideStories,
                NewsSection, BannerAd, AdBox, MostRead, LiveVideo,
                Newsletter, Footer, Logo, Icons
data/home.js    all headlines / links / text
public/images/  logo.png (original logo) + news photos (replace with your own)
```
